Renders

A component's view on the left, and what else it renders on the right: what a terminal shows (renders.tui, the same app: use either), the JavaScript that makes it (renders.js), markdown about it (renders.md), what a model is told about it (renders.llmContext) and the tools a model is given to change it (renders.llmTools, which you can call here). Use it and watch them follow: the tools offered change with the state.
