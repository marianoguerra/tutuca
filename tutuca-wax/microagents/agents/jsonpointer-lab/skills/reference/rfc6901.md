# RFC 6901 in short

```
json-pointer    = *( "/" reference-token )
reference-token = *( unescaped / escaped )
escaped         = "~" ( "0" / "1" )      ; ~0 is "~", ~1 is "/"
```

| key in the document | token in the pointer |
|---|---|
| `name` | `/name` |
| `a/b` | `/a~1b` |
| `m~n` | `/m~0n` |
| `""` (the empty key) | `/` |
| ` ` (a space) | `/ ` |

- Unescape `~1` before `~0`: `~01` is the key `~1`, not `/`.
- Array indexes are `0` or a number with no leading zero: `/items/01` fails.
- `/` alone is the empty key, not the root: the root is `""`.
- In a URI fragment a pointer is percent-encoded and starts with `#` (`#/a%20b`); this lab
  uses the plain string form.
