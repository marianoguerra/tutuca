# JavaScript RegExp flags

| flag | meaning |
|---|---|
| `d` | indices for each match |
| `g` | global: every match (ignored when checking expectations) |
| `i` | ignore case |
| `m` | multiline: `^` and `$` match at line breaks |
| `s` | dotAll: `.` matches newlines |
| `u` | unicode: code points, `\p{…}` classes |
| `v` | unicodeSets: `u` plus set operations in classes |
| `y` | sticky: match only at lastIndex (ignored when checking expectations) |
